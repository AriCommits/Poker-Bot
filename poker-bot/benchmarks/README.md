# Experiment notes

`policy-comparison/` contains the earlier historical comparison; its mixed-snapshot methodology and exclusions are documented there. Each new `comparison-*` directory is a separate run with metadata and raw results. Recent interrupted runs were stopped after timeouts made clean comparisons impossible; do not treat their incomplete results as a strength benchmark. The runner now saves complete baseline and candidate snapshots and uses the frozen candidate copy of the judge and baseline opponents.

The optional preflop candidate was generated with 30,000 random matchups and seed 71. On 30,000 independently sampled matchups with seed 137, mean squared showdown-prediction error was 0.23950 for the original table with the current global-prior fallback, 0.23611 for the candidate, and 0.23874 for a flat 0.5 prior. This is a calibration check, not a match-strength result. The existing table remains active pending a clean candidate-table ablation.

In a local in-process 1,000-hand calling-station profile, the experimental budget and adaptive sampling completed with zero local budget fallbacks. A subsequent full HTTP match under host load exhausted both baseline halves' judge time banks and one candidate half's bank, so no reliable improvement claim can be made from that seed. Local time is an estimate: the judge includes overhead outside the bot's measurement. Run full-length isolated matches and inspect all skipped calls before enabling the experimental features.

## Reevaluation — 2026-11-07

`comparison-20261107-231315-420518/` compares the same frozen working tree with and without the experimental time budget and adaptive sampler, at 1,000 duplicate deals per seed (419 and 431). Clean paired differences in big blinds per deal were -0.824 (approximate 95% interval -2.269 to +0.621) against random and +0.144 (-1.236 to +1.525) against always-pot. Both calling-station and both always-half pairs were excluded because at least one version timed out. Neither version had skipped calls against random or always-pot; the experimental version had zero skipped calls against always-half, while the baseline skipped 2,399. Both versions timed out against calling-station; the baseline skipped 6,495 calls and the experiment 2,500. One opponent half in that experiment also skipped 10 calls. Differences in host load and the bot's local budget fallbacks are not represented by judge skipped-call counts.

`comparison-20261107-232304-127026/` compares the candidate and current preflop tables on the same frozen working tree, with time budgeting and adaptive sampling enabled for both. It used seeds 523 and 541 and 1,000 duplicate deals per seed. The clean random-opponent difference was -0.444 big blinds per deal (approximate 95% interval -1.855 to +0.967). Both always-pot pairs were excluded after the candidate exhausted its time bank. These results do not establish the table's match strength, either alone or under the default sampler.

An independent calibration run with 100,000 matchups and seed 997 yielded mean squared showdown-prediction error of 0.23936 for the current table, 0.23612 for the candidate, and 0.23854 for a flat 0.5 prior. This corroborates the earlier calibration result, but does not measure betting strategy or prove higher match winnings. The experimental settings and candidate table remain disabled by default. Normal-approximation intervals should be treated as exploratory, given the few seeds and potential within-match dependence.
